# 行为评测说明

`cases.json` 是人工或外部评测器可复用的场景清单，`fixtures/sample-paper.md` 是专为分页和图表规则设计的虚构论文材料。示例论文不是真实研究证据，不应用来评价科学结论正确性。

每次评测需记录：使用的模型与宿主、技能版本、完整用户输入、可用材料、是否触发、逐轮输出、预期条款的通过情况。不要只留最终结论。对同一场景至少复测一次，以发现分页或触发的不稳定性。

建议分别评估四类指标：

1. **触发与范围**：系统主题或已指定论文正确进入对应技能；孤立错误、泛泛检索或翻译不误触发。
2. **规则执行**：论文精读的宏观概述独立、后续每批恰好两章；知识讲解的一次性自述收集和前置知识自学边界。
3. **证据与教学**：重要判断能定位来源；材料缺失时降级；例子确实揭示机制；读者能在邻近新情境中应用所学。
4. **跨轮恢复**：局部追问后回到准确的章节或知识单元，不重复、不跳过。

`node scripts/validate.mjs` 只检查案例文件结构，不会替代这些运行评测。
